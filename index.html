Your data

Everything is saved only in this browser. Clearing site data or switching browsers erases it, so export a backup now and then. Importing JSON replaces all current data; Merge JSON adds only what is new from another backup and skips duplicates. Importing a CSV only adds prints (or spools); it skips ones you already have and never changes the rest.

Danger zone

Permanently removes every print, spool, queue item and upkeep task from this browser. Your settings are kept.
